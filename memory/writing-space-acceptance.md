## 代码审查（进程边界与安全）

通过。要点：

- 新 IPC 全部 zod 校验并沿用 mainFrame + 可信 URL 校验；错误统一隐藏系统路径（带 errno 的错误返回通用文案）。
- `files.ts` 所有新操作先过 `location()`；`asset()` 用 `O_NOFOLLOW`；删除只走 `shell.trashItem`，非空文件夹拒绝；资产校验魔数、10 MiB、内容去重。
- `jarvis-writing://` 只处理 GET、只返回媒体类型、Range 边界正确；CSP 只增加 `img-src` / `media-src` / `frame-src jarvis-writing:`，远程图片仍被 CSP 拦截。
- Mermaid `securityLevel: strict` 且锁定安全键，SVG 经 Mermaid 自带净化后插入。
- `find_related_documents` 只读、限同一父文件夹、排除自身、只返回元数据；`report_result` 的共鸣点由主进程复核仍属同文件夹候选；链接写入走版本校验，打开中的文档只改缓冲区；写作助手运行中拒绝改名和关联。

## 退回项（必须修复）

1. **W2 · 紧凑列表编辑后变成松散列表。** 编辑任一列表项后，整个列表重新序列化为每项之间插入空行（`* a\n* b` → `* aZ\n\n* b`），渲染语义从紧凑变为松散，并在其他项产生差异。`roundtrip.ts` 的 `blockText` 没有保留 mdast 的 `spread`。同时有序列表 `1)` 分隔符被改成 `1.`（计划要求保留原列表符号）。请补充：编辑后保留 spread 与有序分隔符，并加入往返用例。
2. **W3 · `/` 面板位置没有跟随光标。** 验收截图 `02-slash-backlinks-*` 中，在「/导图」行（y≈460）触发后，面板出现在编辑区顶部（y≈50–220），压住了路径栏。面板应锚定在触发行下方，空间不足时才翻到上方。
3. **W5 · 左栏星图小窗不可读。** 验收截图 `03-graph-*` 中小窗缩放过小，点和标签几乎看不清；设计稿 `473:39690` 中标签可读、以当前文档为中心显示 1–2 度关系。适配时应以当前点及其 1–2 度邻居为范围，孤岛点放在外圈，设定最小缩放（标签不小于 10px）。

## 小问题（建议本轮一并修复）

4. 文档大标题字重为常规，设计为 32 Bold（`466:38578`）。
5. 反向链接条目直接显示原始 Markdown 片段（如 `# 十月复盘 [[周报草稿]] …`），没有文件图标、路径和链接高亮；设计见 `466:38994`。折叠箭头为文字「▼」，应使用图标。
6. PDF 预览元信息以「· 0.6 KB」开头（缺页数时多了分隔点）；PDF 等非文本标签底部仍显示「已选 0 段」等文本状态栏，应隐藏或改为文件信息。
7. 文件夹只含隐藏文件（如 macOS 的 `.DS_Store`）时，目录树显示为空，但「移到废纸篓」报「文件夹不为空」（`trash()` 用 `readdir` 计入隐藏文件）。代码推断，需在 macOS 确认。
8. 大小写不敏感文件系统上只改大小写的重命名（`a.md` → `A.md`）会被 `absent()` 当作重名拒绝。代码推断，需在 macOS / Windows 确认。
9. 编辑过的块会把 Setext 标题改为 ATX、去掉闭合 `##`、把 `[X]` 改为 `[x]`。只影响被编辑块，可接受；如修复第 1 项时顺带保留更好。
